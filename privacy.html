Privacy Policy

This page explains the categories of information the application may process when you use its location, map, weather and dashboard features.

Location

If you explicitly grant browser location permission, the application may receive latitude, longitude and an accuracy estimate from your device. Location is used to center the globe/map and request location-aware services. The browser controls the permission.

Technical data

The server may process request metadata such as IP address, timestamps, request paths and security logs for reliability, abuse prevention and authentication. Retention depends on the deployment configuration.

External services

Map, geocoding, weather and data feeds may receive the coordinates or query information needed to return the requested result. See Data & Sources for providers and usage notes.

Your choices

You can decline location permission and use manual coordinates. You can stop using the application at any time. Do not enter confidential or sensitive information into analyst notes unless the deployment owner has established an appropriate data-protection process.
